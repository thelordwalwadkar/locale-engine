Locale Engine

Translate, localize and quality-check B2B web pages. Give it a Dutch or English page; get back one version per market: English for the Netherlands and the UK, German for Germany, Austria and Switzerland, and Italian.

Source code on GitHub Open the live demo Read the docs
Status. The engine is complete and fully tested offline (1,780 tests). It has not yet been run against live AI services, and its language rules have not been reviewed by native speakers. Treat every output as a draft.

What it does that a plain translation does not

Translation is not localization

Translate first, then adapt to the market: Swiss "Offerte" and no "ß", British spelling, Austrian "Jänner", formal "Sie" and "Lei".

Rule checks before and after the AI

Numbers, units, brands, links and glossary terms must survive. A market claim like "delivery across the Netherlands" is neutralized and sent to a human.

Every finding has a reason

Each finding is tagged evidence or hypothesis, each change names the rule behind it, and the report ships as Excel, HTML, Markdown and JSON.

Any AI provider

Anthropic, OpenAI, Google, Ollama and any OpenAI-compatible service. Switch per stage with a setting, no code change.

Browser app with limits

Logins, a job queue, side-by-side results and a daily spending limit per user, so a team can share it safely.

CLI, API and MCP

The same engine as a command line, a REST API, and a tool for Claude Desktop.

Try it

  1. In the browser: use the live demo link above (ask the owner for a login).
  2. On your computer, no keys needed: 
    git clone https://github.com/thelordwalwadkar/locale-engine.git
cd locale-engine
npm install && npm run build
LOCALE_WEB_DEMO=1 node dist/web/server.js     # Windows PowerShell: $env:LOCALE_WEB_DEMO=1; node dist/web/server.js
    Open http://127.0.0.1:8080. Demo mode returns placeholder text; add API keys for real translations.
  3. In a ready-made environment: on the repository click Code, then Codespaces.

How a run works

Read the page (respecting robots.txt) → split into typed segments → detect each segment's language → translate (neutral) → localize for the market → check with deterministic rules and an independent AI reviewer → repair what the rules flag → export. A run stops gracefully at its cost ceiling.
